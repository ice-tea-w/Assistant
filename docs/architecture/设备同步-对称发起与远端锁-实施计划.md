# 对称发起 + 远端锁 实施计划

**目标**：让任意一端都能发起一轮目录同步（主机也能主动拉），同时用远端锁保证同一时刻只有一个写入方。

**为什么现在不一致**：连接本身是对称的（每台都监听、都能拨号），不对称的有三处 ——
①`SyncBridge::syncNow()` 在没有对端凭据时直接 return（`src/ui/SyncBridge.cpp:1592`）；
②`NetTransport` 没实现 `tryLock/unlock`（继承 `ITransport` 的恒真默认实现）；
③服务端不处理已定义的 `Lock(0x50)/LockAck(0x51)` 帧。
另外还有一个**做对称才会暴露的缺陷**：`sync.db` 的 `sync_state` 主键只有 `rel_path`，
基线是全局一份 —— 主机同时同步两台设备时会互相污染基线。所以第一步先修基线。

**技术栈**：C++20 / Qt6（QTest）/ SQLite（Qt6::Sql）/ ASYN v2 帧协议。

### Task 3：服务端锁

**Files:** `include/core/net/SyncServer.h`、`src/core/net/SyncServer.cpp`、`tests/test_net_server.cpp`

- [ ] **Step 1：写失败用例** `lockIsExclusiveAndExpires()`

场景：client1 发 `Lock{ttlMs:60000}` → `LockAck{ok:true}`；client2 发 `Lock` → `LockAck{ok:false, holder:"dev-test", retryAfterMs>0}`；
client1 发 `Unlock` → `UnlockAck{ok:true}`；client2 再 `Lock` → `ok:true`；
client1 拿锁后直接断开 → client2 立刻 `Lock` → `ok:true`（断线即释放）。

- [ ] **Step 2：跑失败**（服务端回 `UNSUPPORTED`）

- [ ] **Step 3：实现**

```cpp
// SyncServer.h
void handleLock(Connection &conn, const Frame &frame);
void handleUnlock(Connection &conn, const Frame &frame);
bool lockExpired(qint64 now) const;
QString m_lockHolder;
qint64  m_lockAcquiredMs = 0;
qint64  m_lockTtlMs = 120 * 1000;
```

```cpp
// handleFrame 的 switch 里
case FrameType::Lock:    handleLock(conn, frame);    break;
case FrameType::Unlock:  handleUnlock(conn, frame);  break;
case FrameType::Ping:
    // 持锁方 Ping 即续租
    if (!m_lockHolder.isEmpty() && m_lockHolder == conn.deviceId)
        m_lockAcquiredMs = QDateTime::currentMSecsSinceEpoch();
    send(conn, static_cast<quint8>(FrameType::Pong), frame.reqId, QByteArray());
    break;
```

`handleLock`：解析 `{"ttlMs":N}`（缺省 120000，钳到 5s–10min）；空锁或 `lockExpired(now)` 或 holder 是自己 → 授予 + `LockAck{ok:true, ttlMs}`；否则 `LockAck{ok:false, holder, retryAfterMs}`。
`onDisconnected()` 里在 `m_connections.erase(it)` 之前加：`if (!m_lockHolder.isEmpty() && m_lockHolder == it.value()->deviceId) { m_lockHolder.clear(); Logger::get().info("SyncServer: 持锁设备断开，锁已释放"); }`。

- [ ] **Step 2：实现**

```cpp
bool NetTransport::tryLock(int waitMs)
{
    if (!ensureConnected())
        return false;
    QElapsedTimer timer;
    timer.start();
    while (true) {
        const quint32 reqId = m_nextReqId++;
        QJsonObject body;
        body.insert(QStringLiteral("ttlMs"), kLockTtlMs);
        Frame reply;
        if (!requestJson(FrameType::Lock, reqId, toJson(body), &reply))
            return false;
        const QJsonObject ack = QJsonDocument::fromJson(reply.payload).object();
        if (ack.value(QStringLiteral("ok")).toBool()) {
            m_lockHeld = true;
            return true;
        }
        if (timer.elapsed() >= qMax(0, waitMs))
            return fail(QStringLiteral("对端正在被 %1 同步，稍后再试")
                            .arg(ack.value(QStringLiteral("holder")).toString()));
        m_socket.waitForReadyRead(200);
    }
}

void NetTransport::unlock()
{
    if (!m_lockHeld)
        return;
    m_lockHeld = false;
    if (m_socket.state() != QAbstractSocket::ConnectedState)
        return;
    const quint32 reqId = m_nextReqId++;
    Frame reply;
    requestJson(FrameType::Unlock, reqId, QByteArray(), &reply);
}
```

成员 `bool m_lockHeld = false;`、`static constexpr int kLockTtlMs = 120 * 1000;`。
