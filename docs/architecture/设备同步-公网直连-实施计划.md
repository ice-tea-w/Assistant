## N0：帧编解码与地址解析（已完成）

目标：把一个 `Frame` 编码成字节、从任意切片的字节流里还原出 `Frame`；把
`host:port` / `[v6]:port` / 域名解析成 `PeerAddress`。**不碰 socket，全部可单测。**

- [x] **Step 1**：`include/core/net/SyncFrame.h` 定常量与 `Frame` 结构（magic `ASYN`、
      `kVersion=0x02`、16 字节头、`kMaxPayload=64 KiB`、`FrameType` 0x01–0xFF 全表、flag 位）
- [x] **Step 2**：`FrameDecoder`：`append()` 攒缓冲，`next()` 一次吐一帧；
      半包返回 `NeedMore`、畸形帧返回 `Error` 并**锁死**（后续调用仍返回同一错误）
- [x] **Step 3**：`tests/test_net_protocol.cpp` 写红测试：整帧往返、逐字节喂入、
      两帧挤在一个 chunk、magic/版本/超大 len/截断、64 KiB 边界、`encodeFrame` 越界拒绝
- [x] **Step 4**：`include/core/net/PeerAddress.h` + `parsePeerAddress(input, defaultPort)`：
      `1.2.3.4:45871` / `[v6]:45871` / `[v6]` / 域名:端口 / 域名 / 裸 v6（拒绝，提示加方括号）/
      空、超长、控制字符、端口 0 与 >65535
- [x] **Step 5**：`assistant_net_tests` 目标进 CTest；`net_protocol` 全绿（25 用例）
- [x] **Step 6**：提交 `feat(net): ASYN v2 帧编解码与对端地址解析（N0）`

验收：`assistant_net_tests` 25 用例全绿；逐字节喂入能还原两帧；畸形帧只返回错误、不崩溃。

## N1 开工前的硬边界（设计 §13.1）

1. 线程模型：`NetTransport` 全程用 `waitFor*()` 阻塞 API（工作线程无事件循环）。
2. `List` 必须分页（cursor/limit），不得一次性返回全树。
3. `List` 必须读 `.assistant-sync/index.json`，不得每次重算全树 SHA-256。
4. 锁：全局串行，`NetTransport::tryLock()` 恒真。
