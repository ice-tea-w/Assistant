# M3 安全模块（C++ 实现）

> 实现：`tools/file_guard_cpp/`（C++20，无 Qt/vcpkg/第三方库）
> 接入：主程序直接编译该模块，`SecurityBridge` 调用 C++ API；**无 Python 依赖**。
> 数据目录：`%LOCALAPPDATA%/AssistantTeam/Assistant/security`

## 架构

```
SecurityPage.qml
  └─ SecurityBridge（C++，直连）
       ├─ audit::AuditLog      审计链校验（本地 app.key 派生密钥）
       ├─ BackupStore          备份索引校验 / 版本统计
       ├─ Vault                保险箱状态（初始化与否；解锁需用户口令）
       └─ scan::scanPath       敏感扫描（docx/xlsx/pptx 正文抽取）
```

- 模块在 `tools/file_guard_cpp/`：容器加密、保险箱、扫描、审计、备份、监听、本地服务、完整性；
- 主程序 CMake 直接编译其源文件（`FG_SECURITY_DIR`），链接 `bcrypt/crypt32/ws2_32`；
- `app.key`：随机 32B 本地密钥（ACL 收紧），用于审计/备份索引加密；不是用户口令。

## 验收

```powershell
# 1) 主程序里：主面板 → 安全防护 → 四张卡（审计/备份/保险箱/扫描）
# 2) 点「运行安全体检」→ 卡片刷新；「打开安全报告」→ security-report.txt
# 3) C++ 模块自身测试（独立工程）：
cd tools/file_guard_cpp
cmake -B build -S . && cmake --build build --config Release
.\build\Release\fg_tests.exe tests\data
# → 58/58 通过
```

## 边界

- 保险箱解锁需要用户口令，启动时只显示状态（不做静默解锁）；
- 审计/备份的本地索引使用 app.key（设备本地），不承诺跨机器可读；
- 不承诺运行期内存无明文、SSD 物理擦除、防同账户恶意程序。
