## 目标

原行为：窗口失焦（点窗口外）时 `onActiveChanged` 直接 `backend.hideWindow()` **完全隐藏**。
期望：QQ 式——失焦后窗口滑到屏幕上方，只留一条细边可见；鼠标移上这条边再滑下来。

---

## 技术选型

| 项目 | 选择 | 说明 |
|------|------|------|
| 实现层 | **纯 QML** | 不改 C++，不动 `AppBridge` 可见性状态机 |
| 吸顶动画 | 两个 `PropertyAnimation`（dock/undock）绑定 `window.y` | `Easing.OutCubic`，200ms |
| 触发方式 | `MouseArea { hoverEnabled }` 的 `onEntered` | 吸顶后仅细边在屏内，悬停细边 == 光标进入 MouseArea |
| 细边高度 | `dockStrip = 8` px | 可调；要更易触发调大（12~20），要更彻底隐藏调小 |
| 位置记忆 | `dockRestoreY` 记录吸顶前 `window.y` | 下拉回到原位置 |

## 关键实现

### 状态属性

```qml
property bool docked: false
property int  dockRestoreY: 0
readonly property int dockStrip: 8
```

### 吸顶 / 下拉

```qml
function dock() {
    if (docked) return
    docked = true
    dockRestoreY = window.y
    dockAnim.from = window.y
    dockAnim.to = -(window.height - dockStrip)
    dockAnim.restart()
}

function undock() {
    if (!docked) return
    docked = false
    undockAnim.from = window.y
    undockAnim.to = dockRestoreY
    undockAnim.restart()
    window.requestActivate()
    searchInput.forceActiveFocus()
}
```

### 触发点

```qml
onActiveChanged: {
    if (ready && !active && visible) { dock() }
}

MouseArea {
    anchors.fill: parent
    hoverEnabled: true
    onEntered: { if (docked) undock() }
}
```

> `onActiveChanged` 只在「失焦且仍可见」时吸顶——`Esc`/执行命令/热键/tray 仍走 `backend.hideWindow()`
> **完全隐藏**，语义上「显式关闭」与「失焦折叠」分开。

## 已知取舍

- **悬停触发依赖那条细边**：窗口几乎全在屏幕外，只有细边能收到鼠标事件，这是纯 QML 方案的自然限制；
  若要「碰屏幕顶缘即下拉」（连细边都不留），需改 C++（`QScreen` 边缘检测 + 全局鼠标钩子）。
- **`requestActivate()` 在 `Qt.Tool` 窗口受前台权限限制**：个别情况下拉后焦点可能未落搜索框，需点一下才能输入。
  若复现，可改「悬停只展开、点击才聚焦」或补 `backend.activate()`。
- **多显示器**：当前以「主屏顶部」为吸顶目标，未处理副屏/任务栏高度；后续 Phase 3 可让吸顶目标跟随窗口所在屏幕。

# 鼠标点选（单击选中 / 再击执行）

## 目标

原交互仅靠方向键 + 回车。期望：鼠标也能全程操作——点击结果项选中，再次点击同一项执行，
不再依赖键盘。

## 技术选型

| 项目 | 选择 | 说明 |
|------|------|------|
| 实现层 | **纯 QML**，delegate 内加 `MouseArea` | 不改 C++ |
| 选中状态 | 独立 `mouseSelectedIndex`（初始 `-1`） | 与 `currentIndex` 分离，避免默认选中导致首击即执行 |
| 执行判据 | `mouseSelectedIndex === index` 时视为「第二次点击」 | 首击仅 `currentIndex = index` 高亮 |

## 修改文件

| 文件 | 变更 |
|------|------|
| `resources/qml/MainWindow.qml` | 新增 `mouseSelectedIndex` 状态；delegate 加 `MouseArea`（单击选中/再击执行）；在 `onTextChanged`/Up/Down/`onVisibleChanged` 四处复位 `mouseSelectedIndex` |

## 关键实现

```qml
MouseArea {
    anchors.fill: parent
    onClicked: {
        if (window.mouseSelectedIndex === index) {
            backend.executeCommand(index)
            window.mouseSelectedIndex = -1
        } else {
            window.mouseSelectedIndex = index
            resultsList.currentIndex = index
        }
    }
}
```

> 复位的必要性：`ListView` 默认 `currentIndex = 0`，若直接以 `currentIndex` 判「是否已选中」，
> 首次点击第 0 条会立即执行。独立 `mouseSelectedIndex` 从 `-1` 起步，首击必走「选中」分支。

### 复位点（防误执行）

- `onTextChanged`：新查询 → `mouseSelectedIndex = -1`
- `Keys.onUpPressed / onDownPressed`：键盘移动 → 清 `-1`（键盘/鼠标两套选中互不污染）
- `onVisibleChanged`（显示时）：窗口重新显示 → 清 `-1`
