## 关键实现点

- **头布局固定 16 字节**：`magic(4) ver(1) type(1) flags(2) reqId(4) len(4)`，全部小端。
  `len` 超过 `kMaxPayload` 立即报错、不进入等待 —— 防止对端用"超长声明"把缓冲撑爆。
- **解码器错误是锁死的**：一旦 `fail()`，`append()` 不再收数据、`next()` 永远返回同一个
  错误。调用方看到 `Error` 就该断开连接，不需要自己再判重入。
- **`NeedMore` 与 `Error` 严格分开**：截断只是数据没到齐（`buffered()` 保留原字节），
  调用方可以继续 `append()`；只有 magic / 版本 / 长度 / 内部契约违规才算错误。
- **`parsePeerAddress` 不猜**：裸 IPv6 字面量一律拒绝并提示加方括号（`2001:db8::1` 带端口
  必然有歧义）；端口 0 与 >65535 拒绝；主机名只允许 `[A-Za-z0-9._-]`，含空格/控制字符拒绝。
- 地址解析放到 `Sync::Net` 命名空间，与 `Sync::Net::Frame` 同层，将来 `NetTransport` 直接用。
