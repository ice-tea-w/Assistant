# 2026-11-12 直连页：监听地址列出全部网卡 + 网络现状实测

## 做了什么

用户问「监听地址怎么只有一个，能不能都列出来」。原来 `SyncBridge::netAddress` 只取
`localIpv4()` 返回的第一个非回环 IPv4，多网卡顺序不确定（本机优先命中 Tailscale）。

- `include/ui/SyncBridge.h`：新增 `Q_PROPERTY(QVariantList netAddresses)`、getter、私有
  `QVariantList addressCandidates(quint16 port) const`、成员 `m_netAddresses`。
- `src/ui/SyncBridge.cpp`：`addressCandidates()` 遍历 `QNetworkInterface::allInterfaces()`，
  跳过 down/loopback、跳过非 IPv4 与 link-local，按地址去重，每项 `{name, address}`
  （`address` 已带 `:<端口>`）；`startNetServer()` 的 listen 成功回调里填充它，
  线程 `finished` 里与 `m_netAddress` 一起清空。
- `resources/qml/SyncPage.qml`：原来「本机地址 + 复制」单行换成 `Repeater` 列表，
  每行 `网卡名 / IP:端口 / 复制`；未监听时仍显示一行提示。
- 保留 `netAddress`（首选地址）给状态行「正在监听 %1 · 本机指纹 %2」用。

## 顺带测到的两件事（影响真机走查）

1. **WLAN 没有 IPv6**：`IPv4Connectivity = Internet` 但 `IPv6Connectivity = NoTraffic`、
   无 `::/0` 默认路由、`Test-NetConnection 2400:3200::1:443` = False，地址只有 `fe80::`。
   → 该 SSID 只跑 IPv4，公网 IPv6 直连这条路在当前网络不成立（不是没认证，IPv4 已通外网）。
2. **没有 45871 的入站防火墙规则**，且 `i-HDU 2` 的 NetworkCategory 是 `Public`。
   → 当主机前必须放行，否则外部连接一律被拦：
   `New-NetFirewallRule -DisplayName "Assistant 直连 45871" -Direction Inbound -Protocol TCP -LocalPort 45871 -Action Allow -Profile Private,Public`

## 仍未验证

两台真机从没跑过，全部链路验证仍是同进程回环（`net_engine` 用例）。
