## 架构设计

### SearchEngine（C++ → QML 桥接）

```
┌─────────────────────────────────┐
│  SearchEngine : QObject         │
│  ───────────────────────────    │
│  Q_PROPERTY(results)            │
│  Q_INVOKABLE search(query)      │
│  Q_INVOKABLE activate()         │
│  signal resultsChanged()        │
│  ───────────────────────────────│
│  m_allItems  ← Phase 1 硬编码   │
│  m_results   ← 过滤后结果       │
└─────────────────────────────────┘
```

- `results` 属性绑定到 QML `ListView.model`，信号驱动自动刷新
- `search(query)` 不区分大小写子串匹配
- `activate()` 在窗口弹出时重置为全部条目

### 窗口行为

| 操作 | 行为 |
|------|------|
| `Alt+Space` / 托盘点击 | 窗口居中于屏幕上方 1/4 处弹出，搜索框自动获焦 |

## 踩坑记录

### 1. `StringList` vs `QStringList`

**现象：** `error C1083: 无法打开包括文件: "StringList"`

**根因：** 头文件里写成了 `#include <StringList>`，少了 `Q` 前缀。

**修复：** `#include <QStringList>`

### 2. 类定义结尾缺少分号

**现象：** 编译器把 `int main` 当成 `SearchEngine` 的成员，报 `"main"的返回类型应为"int"而非"SearchEngine"`。

**根因：** `SearchEngine.h` 类 `}` 后面缺 `;`，预处理器把后续所有代码吞进类定义。

**修复：** `};` 分号不能省。

### 3. `main.cpp` 缺少 QQmlContext / QScreen 头文件

**现象：** `QQmlContext` 和 `QScreen` 使用了未定义类型。

**修复：** 补上 `#include <QQmlContext>` 和 `#include <QScreen>`。

### 4. QML 手动编辑截断问题

**现象：** 多次出现 `tr` 不是 `true`、`fa` 不是 `false`、`pa` 不是 `parent`、`searcurrentIndex]` 等截断错误。

**根因：** 手动复制粘贴 / 编辑时退格吃掉了相邻字符。

**教训：** QML 这类对语法敏感的文件，建议整文件写入而非逐行编辑。

### 5. `Keys` 不能挂在 `ApplicationWindow`

**现象：** `Could not attach Keys property to: ... is not an Item`

**根因：** `ApplicationWindow` 继承自 `Window`（非 `Item`），`Keys` 只能附加到 `Item` 类型。

**修复：** 将 `Keys.onXxx` 移到内层 `Rectangle`（继承自 `Item`）中，并给 `Rectangle` 设置 `focus: true`。

### 6. `Keys.onDownPressed` 缺少 `}`

**现象：** 启动即闪退，QML 引擎静默崩溃。

**根因：** `Keys.onDownPressed` 代码块少了一个 `}`，导致后续 `ColumnLayout` 被错误解析。

**修复：** 补上缺失的闭合括号。

### 7. `onActiveChanged` 启动时误触发

**现象：** 窗口弹出后一闪即消失。

**根因：** `Qt.FramelessWindowHint | Qt.Tool` 的窗口在 Windows 上初始化时 focus/activate 事件时序不确定，可能在 QML 内部状态未就绪时就触发了 `visible = false`。

**修复：** 加 `property bool ready: false` + `Component.onCompleted: ready = true` 守卫，`onActiveChanged` 里检查 `ready` 后才执行隐藏逻辑。

### 8. 托盘连接重复

**现象：** 旧 toggle lambda 未删除，和新的定位版 lambda 同时存在，两次 `setVisible` 冲突导致闪烁。

**修复：** 删掉旧的 raw toggle 连接。
