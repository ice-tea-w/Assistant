## 碰到的问题

### CMake 报错：找不到编译器

**现象：** `CMAKE_CXX_COMPILER not set`、找不到 Ninja

**原因：** MSYS2 UCRT64 默认不带 GCC 和 Ninja

**解决：**
```bash
pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-ninja
```

### 链接失败：全部 undefined reference

**现象：** 几十个 `__imp__ZN...undefined reference` 错误

**原因：** vcpkg 的 Qt6 是 MSVC 版本（x64-windows），编译器是 MinGW GCC，ABI 不匹配

**解决：** 安装 VS2022 Build Tools，用 MSVC 编译器匹配

## 知识点

- **ABI 匹配原则：** vcpkg 用哪个 triplet，编译器就得用哪个体系的
  - `x64-windows` → MSVC
  - `x64-mingw-static` → MinGW GCC
- **QML 方案不需要 AUTOUIC**：`CMAKE_AUTOUIC` 仅用于 `.ui` 文件（Widgets Designer），QML 只需 `AUTOMOC` + `AUTORCC`
- **vcpkg 安装大型库很慢：** Qt6 首次安装需 30-60 分钟，要有耐心
