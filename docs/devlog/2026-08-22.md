## 关键实现要点

### 🏠 按钮 → 主面板（Step 1）

- `MainWindow.qml` 搜索框 `RowLayout` 末尾加 🏠 `Rectangle + MouseArea`，`onClicked → backend.openMainPanel()`
- `AppBridge::openMainPanel()` 仅 `emit mainPanelRequested()`
- `main.cpp` 连接该信号：`panelWindow->show()+raise()+requestActivate()`，再 `backend.hideWindow()` 隐藏搜索浮窗
- 主面板 `onClosing` 拦截为 `hide()`，保证常驻、下次 🏠 重新 show

### 剪贴板去重 + 置顶（Step 5）

`ClipboardDatabase::addClip` 两段逻辑：
1. 与最近一条相同 → 跳过（连续复制同一内容不刷屏）
2. 否则删除历史中所有同内容旧条目再插入 → 「重新复制即置顶」，且 `copyClip` 写回剪贴板触发 `dataChanged` 后不会产生重复条目

### 记事本防抖自动保存（Step 4）

`Timer { interval: 500 }` + `onTextChanged` 里 `saveTimer.restart()`；`loading` 标志防止程序性赋值（loadNote/newNote）触发保存；`PanelBridge::addNote` 改为返回新 id 以便新建后立即选中。

### 待办勾选划去（Step 3）

`toggleDone` 单条 SQL 依赖 SQLite「UPDATE 的 SET 表达式基于旧行值」语义：
`done = 1 - done, completed_at = CASE WHEN done = 0 THEN now ELSE NULL END`。

## 已知取舍 / 踩坑

1. **编译必须 `danger-full-access`**：本环境 sandbox 会阻止 CMake/AUTOMOC 调用 `moc.exe` 子进程
   （报 `libuv process spawn failed: operation not permitted`）。`workspace-write` 不够，需逐次授权。
2. **QML 页面主题色重复**：4 个 `*Page.qml` 各自从 `config.theme` 派生一份颜色（与 `MainPanel` 一致）。
   后续可抽成共享 `Style.qml` 单例，Phase 3 当前先接受重复。
3. **剪贴板监听与 `copyClip` 自触发**：靠 `addClip` 的「同内容删旧插新」语义消化，未用 suppress 标志。
4. **热键修改 / 开机启动未实现**：设置页仅显示当前热键 + 开机启动 Switch 占位，Phase 3 后续再补
   （热键捕获需 `Keys.onPressed` 记录组合键 + 重注册；开机启动写 `HKCU\...\Run`）。
5. **`Logger::get()` 在 init 前被调用**（`ConfigManager::load` 早于 `Logger::init`）——既有的启动期
   fallback 警告，非本次引入，但值得后续把 Logger::init 提前到 config.load 之前。
