## Qt 部署方案（vcpkg 开发阶段）

### 问题演进

1. **`qt.qpa.plugin` 找不到 `windows`** — exe 找不到 `platforms/qwindowsd.dll`
2. **`module "QtQuick.Controls" is not installed`** — QML 引擎找不到 QML 插件 DLL
3. **`Cannot load library qtquick2plugind.dll`** — QML 插件找到了，但 Windows 加载器找不到它的依赖 `Qt6Quickd.dll`

### 最终方案：qt.conf + run.bat

```ini
# qt.conf（Qt 内部路径，在 exe 同级目录）
[Paths]
Prefix = C:/vcpkg/installed/x64-windows/debug
Plugins = Qt6/plugins   → 找到 qwindowsd.dll
QmlImports = Qt6/qml    → 找到 QtQuick / QtQuick.Controls
```

```batch
:: run.bat（Windows DLL 加载器 PATH）
set "PATH=C:/vcpkg/installed/x64-windows/debug/bin;%PATH%"
Assistant.exe
```

### 两个机制各司其职

| 机制 | 负责 | 例如 |
|------|------|------|
| `qt.conf` | Qt 内部查找 | `platforms/`、`qml/` 子目录 |
| `PATH` | Windows 加载器 (LoadLibrary) | QML 插件反过来依赖的 `Qt6Quickd.dll` 等 |

### CMakeLists.txt 实现

`qt.conf` 和 `run.bat` 均通过 `add_custom_command(POST_BUILD ...)` 在编译后自动生成到 `build/Debug/`。
