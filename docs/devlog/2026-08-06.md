## Step 1 — spdlog 日志系统

### 新增文件

| 文件 | 职责 |
|------|------|
| `include/core/Logger.h` | 命名空间级单例，`init()` / `get()` / `setLevel()` |
| `src/core/Logger.cpp` | 双 sink：控制台彩色输出 + 文件滚动（5MB × 3）|

### 修改文件

| 文件 | 变更 |
|------|------|
| `CMakeLists.txt` | 取消注释 `find_package(spdlog REQUIRED)` + `target_link_libraries spdlog::spdlog` |
| `include/core/ConfigManager.h` | 新增 `Q_PROPERTY(QString logLevel ...)` + getter/setter/signal |
| `src/core/ConfigManager.cpp` | JSON 读写 `"logging": { "level": "..." }`，默认值 `"info"` |
| `src/main.cpp` | `Logger::init()` 初始化，在 ConfigManager load 之后立即调用 |
| `src/core/HotkeyManager.cpp` | 全部 `qDebug()`/`qWarning()` → `Logger::get()` |
| `src/core/ConfigManager.cpp` | 全部 `qInfo()`/`qWarning()` → `Logger::get()` |

### 架构决策

- **不用 QObject**：Logger 是基础设施，不是 QML API，用命名空间级单例更简洁
- **双 sink**：`stdout_color_sink_mt`（控制台）+ `rotating_file_sink_mt`（文件，5MB × 3 个滚动文件）
- **日志格式**：`[2026-08-05 19:40:27.323] [info] [assistant] message`
- **级别来源**：从 ConfigManager JSON 读取 `logging.level`，运行时可通过 `Logger::setLevel()` 切换
- **fallback**：如果在 `init()` 之前调用 `get()`，自动创建 console-only fallback logger
- **fmt 兼容性**：vcpkg 构建 spdlog 时强制 `SPDLOG_FMT_EXTERNAL=ON`，链接 vcpkg 统一管理的 `fmt` 包，与 Qt6 不冲突

## Step 2 — SQLite 搜索历史（Qt6::Sql）

### 新增文件

| 文件 | 职责 |
|------|------|
| `include/database/HistoryDatabase.h` | QObject 封装，3 张表的 CRUD + 清理 |
| `src/database/HistoryDatabase.cpp` | WAL 模式、建表、插入/查询、定期清理 |

### 修改文件

| 文件                       | 变更                                                                   |
| ------------------------ | -------------------------------------------------------------------- |
| `CMakeLists.txt`         | `find_package Qt6` 新增 `Sql` 组件；`target_link_libraries` 新增 `Qt6::Sql` |
| `include/ui/AppBridge.h` | 新增 `setHistoryDatabase()` + `HistoryDatabase *m_historyDb` 成员        |
| `src/ui/AppBridge.cpp`   | `search()` 末尾记录搜索历史；`executeCommand()` 记录命令执行                        |
| `src/main.cpp`           | 实例化 `HistoryDatabase`，传 `dbPath` 并 `open()`，传入 `AppBridge`           |

### 架构决策

- **用 Qt6::Sql 而非原始 sqlite3**：Qt6 内置 SQLite 驱动，`QSqlDatabase`/`QSqlQuery` 是 Qt 惯用写法，无需额外 vcpkg 包
- **WAL 模式**：`PRAGMA journal_mode=WAL` + `PRAGMA synchronous=NORMAL`，支持并发读写
- **数据库路径**：`%LOCALAPPDATA%/AssistantTeam/Assistant/history.db`，与 `config.json` 同级
- **3 张表**：`search_history`（搜索记录）、`command_history`（命令执行计数）、`app_launch_history`（应用启动频次）
- **搜索历史触发条件**：`query.trimmed().length() >= 2`，避免记录空查询
