## 关键技术点

### TrayManager

- `QSystemTrayIcon` 必须在 `QApplication`（非 `QGuiApplication`）下工作
- `setQuitOnLastWindowClosed(false)` — 关窗口不退出，托盘常驻
- 托盘图标用 QPainter 代码绘制（蓝色圆点），Phase 1 不引入图标资源
- 信号：`toggleWindowRequested()` / `quitRequested()`

### HotkeyManager

- 实现 `QAbstractNativeEventFilter`，拦截 `WM_HOTKEY` 消息
- Windows API: `RegisterHotKey(HWND, id, modifiers, vk)` + `UnregisterHotKey`
- `parseModifiers()` 支持 `Alt` / `Ctrl` / `Shift` / `Win` 及组合（`+` 连接）
- `parseKey()` 支持 `A-Z`、`0-9`、`F1-F24`、常见命名键（Space/Escape/Tab/Enter）
- HWND 来源：QML 顶层 `QWindow::winId()`

## 踩坑记录

### 1. 中文 UTF-8 → MSVC C2001 常量中有换行符

**根因：** 手动创建的 `.cpp` 文件存为 UTF-8（无 BOM），MSVC 默认按 GBK 解析，中文"显示"的字节 `\xe6\x98\xbe` 被当成非法字符。

**修复：**
- `CMakeLists.txt` 加 `if(MSVC) add_compile_options("/utf-8") endif()`
- 菜单文字改用英文（`"Show / Hide"` / `"Quit"`）避免编码问题
- 如果后续需要中文 UI，用 `QString::fromUtf8()` 写十六进制字面量，或统一保存为 UTF-8 with BOM

### 2. `#include <Qpixmap>` 大小写

- Qt 头文件区分大小写，正确是 `QPixmap`（大写 P）
- 手写时 VS Code 没有实时纠错，编译才报

### 3. `file(GLOB_RECURSE)` 只在 configure 阶段扫描

**现象：** 新增 `.cpp` 后直接 `cmake --build`，链接报 LNK2019 找不到符号。

**原因：** CMake 的 `GLOB_RECURSE` 在 `cmake -B build -S .` 时展开，之后新增文件不会被自动发现。

**解决方案：**
- 每次加新文件后重新跑一次 configure（`cmake -B build -S . ...`）
- 或改用 `file(GLOB_RECURSE SOURCES CONFIGURE_DEPENDS src/*.cpp)` — MSBuild 会自动检测并 reconfigure

### 4. AUTOMOC 不生成 moc 文件（待验证）

配置后 HotkeyManager.h 出现在 AutogenInfo.json 中但 `moc_HotkeyManager.cpp` 未生成，链接报 `qt_metacall` 等缺失。

**尝试：** `cmake --build build --config Debug --clean-first` 清理重编。
