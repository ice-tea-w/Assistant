## 目标

输入文件名（如 `report.docx`、`照片`）→ 模糊匹配用户目录中的文件 → Enter 用默认程序打开。

实现四件事：

1. `QDirIterator` 递归索引用户常见目录的文件名
2. 建立内存索引，`FuzzyMatcher` 对文件名打分
3. 结果作为 type=File 注入搜索结果，按分数排序
4. 限制条数，防止输入单字符时列表卡顿

---

## 技术选型

| 项目 | 选择 | 说明 |
|------|------|------|
| 索引方式 | **内存索引 + QDirIterator** | 启动时一次性建立，之后每次按键只做内存 fuzzy 扫描，避免每次按键都递归磁盘 |
| 索引目录 | `QStandardPaths` 六个位置（Desktop/Documents/Downloads/Pictures/Music/Movies） | 不索引 Home 根目录（含 AppData 等配置噪音） |
| 隐藏目录跳过 | QDirIterator 默认过滤（不设 `QDir::Hidden`） | Windows 下自动跳过隐藏属性目录（AppData、`$RECYCLE.BIN`）；再补一个跳过名单（`node_modules`、`__pycache__` 等非隐藏但巨大目录）|
| 索引上限 | `kMaxIndexedFiles = 20000` | 同时限制内存占用与单次按键的最坏扫描成本 |
| 模块形态 | `FileSearcher` 命名空间（非 QObject） | 与 AppIndexer/FuzzyMatcher/Calculator 一致，不面向 QML |
| 打开方式 | `QDesktopServices::openUrl(QUrl::fromLocalFile(path))` | 底层 ShellExecute，用默认程序打开任意文件类型 |

## 关键实现

### 索引（buildIndex）

```cpp
QDirIterator it(root, QDir::Files | QDir::NoDotAndDotDot,
                QDirIterator::Subdirectories);
while (it.hasNext() && s_index.size() < kMaxIndexedFiles) {
    it.next();
    if (inSkippedDir(it.filePath())) continue;
    Entry e{ it.fileName(), it.filePath(), 0 };
    s_index.append(e);
}
```

> 循环条件里同时判断索引上限，一旦触顶即停止，`Logger` 输出 warn。

### 搜索（search）

对索引逐个 `FuzzyMatcher::score(query, e.name)`，`> 0` 的进候选；按 score 降序、name 字典序升序排序；`erase` 截断到 `limit`。

### 结果注入（AppBridge::search）

文件**不**进 `m_allItems`——否则空查询默认列表会返回全部 2 万条导致 QML ListView 卡死。文件结果只在非空查询时追加，`priority=1` 让同分时 builtin/app 优先。

```
search(query)
  ├─ builtin + app：FuzzyMatcher 打标题
  ├─ file：FileSearcher::search(query, 20) → type=File, id="file://<path>"
  ├─ 统一排序（score 降序 → priority 降序）
  └─ calculator：score=1001 置顶（仍高于文件 exact 的 1000）
```

### 执行分发（executeCommand）

新增分支：

```
executeCommand(index)
  ├─ type == Calculator  → 复制到剪贴板
  ├─ id 以 "app://" 开头  → openUrl + recordAppLaunch
  ├─ type == File        → QDesktopServices::openUrl(fromLocalFile(path))   ← 新增
  └─ 其余                → executeAction() + recordCommandExecution()
```

## 已知取舍

- **启动延迟**：`buildIndex()` 在窗口显示前同步执行，Documents 很大时首启会慢。当前用索引上限兜底；
  Step 8 可考虑 `QtConcurrent` 异步索引或首次按键懒加载。
- **遍历浪费**：QDirIterator 无法跳过子树，`node_modules` 仍会被遍历（但不索引其中文件）。
  若未来遇到大目录，可改为手写递归（`QDir` + 跳过名单）精确剪枝。
