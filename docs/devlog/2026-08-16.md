## 关键实现

### 类型 → 字形/颜色映射

```qml
function typeGlyph(t) {
    switch (t) {
        case "app":        return "▶"
        case "file":       return "▤"
        case "calculator": return "#"
        case "url":        return "↗"
        default:           return "⚡"
    }
}

function typeColor(t) {
    switch (t) {
        case "app":        return accentColor
        case "file":       return isDark ? "#5b8f5b" : "#4c8a4c"
        case "calculator": return isDark ? "#8f6bd1" : "#7a58c4"
        case "url":        return isDark ? "#3d9ba8" : "#2f8b98"
        default:           return isDark ? "#5a5a5a" : "#a0a0a0"
    }
}
```

> app 用主题 `accentColor`，其余用暗/亮两套 tint；徽章白字、`radius: 6`、`26×26`。
> 「builtin」走 `default` 分支，用中性灰，视觉上比 app/file 更低调。

### 键盘导航两处补强

```
onTextChanged        → backend.search(text); resultsList.currentIndex = 0
onCurrentIndexChanged → if (currentIndex >= 0) positionViewAtIndex(currentIndex, Contain)
```
