## 目标

输入应用名（如 `chrome`、`notepad`）→ 模糊匹配 Start Menu 中的应用 → Enter 启动。

实现四件事：

1. 扫描用户 + 所有用户 Start Menu 的 `.lnk` 文件
2. 解析每个快捷方式的目标路径
3. 注册到 `m_allItems`（type=App）
4. 复用现有 FuzzyMatcher 做应用名模糊搜索

---

## 技术选型

| 项目 | 选择 | 说明 |
|------|------|------|
| `.lnk` 解析 | **Windows Shell Link COM** (`IShellLinkW` + `IPersistFile`) | 官方唯一可靠方式；手写 `.lnk` 二进制解析脆弱 |
| 扫描目录 | `SHGetKnownFolderPath` → `FOLDERID_Programs` + `FOLDERID_CommonPrograms` | 比硬编码路径更稳健（用户/所有用户两处） |
| COM 初始化 | `CoInitializeEx(COINIT_APARTMENTTHREADED)`，仅 `S_OK` 时 `CoUninitialize` | Qt 主线程已是 STA，通常返回 `S_FALSE`（已初始化）|
| 模块形态 | `AppIndexer` 命名空间（非 QObject）| 与 Logger/FuzzyMatcher/Calculator 一致：不面向 QML，保持轻量 |
| 启动方式 | `QDesktopServices::openUrl(QUrl::fromLocalFile(path))`，失败回退 `QProcess::startDetached` | ShellExecute 底层能处理 exe/msi/文件夹/URL |

## 关键实现

### `.lnk` 解析（resolveShortcut）

```cpp
CoCreateInstance(CLSID_ShellLink, ..., IID_IShellLinkW, &shellLink);
shellLink->QueryInterface(IID_IPersistFile, &persist);
persist->Load(lnkPath.utf16(), STGM_READ);      // QChar 在 Windows 就是 UTF-16
shellLink->GetPath(buf, 4096, nullptr, 0);      // 0 = 长路径（非 8.3 短路径）
```

> 注意 `GetPath` 第三个 flag 用 `0`（长路径），**不要**用网上教程常见的 `SLGP_UNCPRIORITY`——那会把本地路径转成 UNC 形式。

### 去重 + 排序

同一应用（相同解析路径）会同时出现在用户菜单和公共菜单 → 按 `path.toLower()` 去重；
最终按应用名 `Qt::CaseInsensitive` 排序，保证空查询时的默认列表稳定友好。

### 启动分发（executeCommand）

通过 id 前缀 `app://` 区分「索引应用」与「内置命令」——内置的 "Open Notepad" 虽然 type 也是 App，
但 id 是 `cmd://opennotepad`，走原有 `executeAction()`，不会误入应用启动分支。

```
executeCommand(index)
  ├─ type == Calculator  → 复制到剪贴板
  ├─ id 以 "app://" 开头 → openUrl(path) + recordAppLaunch(name, path)
  └─ 其余               → executeAction() + recordCommandExecution()
```
