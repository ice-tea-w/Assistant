### FuzzyMatcher 五级打分

| 级别 | 条件 | 分值 |
|------|------|:--:|
| 精确匹配 | 忽略大小写完全相同 | 1000 |
| 前缀匹配 | text 以 query 开头 | 900 |
| 词边界匹配 | query 匹配空格/`-`/`_`/`.` 之后的词首 | 800 |
| 包含匹配 | text 包含 query（越靠前越高） | 600~400 |
| 编辑距离 | ≤10 字符 & ≤30 字符，相似度 ≥50% | 400~0 |

## Step 4 — Calculator 递归下降解析器

### 新增文件

| 文件 | 职责 |
|------|------|
| `include/core/Calculator.h` | `Calculator::tryParse()` 命名空间接口 |
| `src/core/Calculator.cpp` | 递归下降解析器：Lexer (tokenizer) + Parser (expr → term → factor)，支持 PEMDAS + 一元正负号 + 括号 + 除零检测 |

### 修改文件

| 文件 | 变更 |
|------|------|
| `include/ui/SearchResult.h` | 新增 `resultText` 字段（Calculator 结果展示，如 `"= 42"`），`toMap()` 输出 `"result"` 键 |
| `src/ui/AppBridge.cpp` | `#include "core/Calculator.h"`；`search()` 末尾新增计算器检测：含数字+运算符 → tryParse → 成功则 prepend Calculator 结果（score=1001）；`executeCommand` 对 Calculator 型结果复制到剪贴板 |
| `resources/qml/MainWindow.qml` | title 行右侧显示 `modelData.result`（accentColor，非空时可见）|

### 语法（PEMDAS）

```
expr   → term (('+' | '-') term)*
term   → factor (('*' | '/') factor)*
factor → ('+' | '-') factor | '(' expr ')' | NUMBER
```

### 计算器检测触发条件

1. query 去空白长度 ≥ 3
2. 至少含 1 个数字 `[0-9]`
3. 至少含 1 个运算符 `+ - * /`

全部满足才尝试解析，失败静默跳过。成功 → score=1001 置顶。

### 架构决策

- **不用 Qt Script / QJSEngine**：太重，且 QJSEngine 在 Qt6 中功能受限
- **异常处理**：解析失败抛 `std::runtime_error`，`tryParse()` 内部 catch 后返回 false + error 消息
- **浮点格式化**：整数结果去掉 `.0`（`static_cast<long long>` 检查），非整数用 `'g'` 格式最多 10 位有效数字
