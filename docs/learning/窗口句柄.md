
## 1. 直白定义
**句柄(Handle)**：操作系统给每一个窗口分配的**唯一编号/身份证**。
Windows 里窗口句柄类型名字就叫 `HWND`（Handle to Window）。

你可以这样理解：
- 操作系统 = 一栋大楼
- 每一个窗口（桌面、记事本、Qt程序窗口、弹窗）= 一间房间
- **HWND = 房间门牌号**

程序想要操作某个窗口，不能直接访问窗口内存，把「门牌号」交给 Windows API，系统就能找到对应的窗口。

## 2. 本质
底层上 HWND 并不是窗口内存指针（不要当成普通指针！），
它是一个**不透明标识**：只是一个整数，Windows 内核维护一张映射表：
`HWND值 → 窗口内核对象`。
应用程序只负责传递这个编号，由操作系统真正查找、操作窗口。

## 3. 常见可以做的操作（传入HWND调用Win32接口）
```cpp
// 向窗口发送消息
SendMessage(hwnd, WM_XXX, ...);

// 设置窗口大小、置顶、隐藏窗口
SetWindowPos(hwnd,...);

// 注册全局热键：热键触发后系统把消息发给这个hwnd窗口
RegisterHotKey(hwnd, id, mod, vk);
```

## 4. 和你 HotkeyManager 的关联（重点！）
```cpp
RegisterHotKey(hWnd, m_hotkeyId, mod, vk);
```
含义：
> 告诉 Windows：当用户按下这个快捷键，**请把 WM_HOTKEY 消息投递到 hWnd 对应的窗口**。

流程：
1. 按下快捷键
2. Windows 根据HWND找到目标窗口
3. 将 `WM_HOTKEY` 放入该窗口的消息队列
4. Qt捕获原生消息，进入 `nativeEventFilter`，触发热键信号

⚠️ 关键规则再次强调：
**注销热键 UnregisterHotKey 必须传入同一个HWND！**
门牌必须一致，不然系统找不到当初注册的热键，注销失效。

## 5. Qt 中如何拿到窗口句柄
Qt 封装好了：`QWidget::winId()`
```cpp
WId wid = this->winId();
// Windows平台 WId 等价于HWND，转为 void* 传入你的接口
hotkeyMgr->registerHotkey("Ctrl+C", "A", reinterpret_cast<void*>(wid));
```

## 6. 容易踩坑的常识
1. **窗口销毁后，HWND立即失效**
窗口关闭，门牌号作废；继续使用会造成API调用失败。
2. 不同进程HWND互相独立，但可以跨进程使用合法HWND发送消息
3. HWND只在Windows存在；Linux(X11)、macOS有各自不同的窗口ID概念，不能混用。

## 极简总结
**HWND（窗口句柄）就是Windows系统给每个窗口分配唯一“门牌号”。
程序通过这个编号，让操作系统找到指定窗口、投递消息、执行窗口相关操作。
你的全局热键，就是依靠这个编号告诉系统：热键消息要发给哪个窗口。**
