# 市场调研与功能构思

> 日期：2026-08（调研）
> 目标：梳理市面上主流桌面助手的功能布局，为 Assistant 的 Phase 3 及后续阶段提供功能候选清单。

## 一、市面主流桌面助手速览

### 1. 启动器类（Launcher）—— 与 Assistant 定位最接近

| 工具 | 平台 | 呼出方式 | 核心能力 | 对我们的启发 |
|------|------|----------|----------|--------------|
| **uTools** | Win/macOS | Alt+Space | 插件生态（聚合搜索、翻译、剪贴板、OCR、待办、流程图…） | 统一搜索框 + 插件化是主流形态；"一个入口干所有事" |
| **Listary** | Windows | 双击 Ctrl | 文件搜索、快速切换、快捷命令、与资源管理器深度集成 | 文件搜索体验标杆；"在任意窗口里都能呼出" |
| **Wox / Flow Launcher** | Windows | Alt+Space | 开源启动器，Wox 已停更，Flow Launcher 是继任者 | 插件市场（Snippets 文本模板等） |
| **PowerToys Run** | Windows | Alt+Space | 微软官方：应用/文件/计算器/窗口跳转/命令 | 稳定、系统集成深 |
| **Raycast / Alfred** | macOS（Raycast 已有 Win 版） | 快捷键 | 剪贴板、窗口管理、AI、大量扩展 | 效率工具天花板，功能聚合度高，AI 已入场 |

### 2. 效率工具箱类

| 工具 | 核心功能 | 对我们的启发 |
|------|----------|--------------|
| **PowerToys** | FancyZones 分屏、Always On Top 置顶、Color Picker 取色、Text Extractor 截图 OCR、Keyboard Manager 键位映射、PowerRename 批量重命名 | "小工具全家桶"模式，每个功能都不大但很实用 |
| **Quicker** | 按键/鼠标中键弹出动作面板，文本处理、截图、窗口操作等自动化动作 | 把常用动作"一键化"的思路 |
| **WinKit** | TodoList + Clipboard 深度整合，毛玻璃 UI | 待办和剪贴板是用户高频刚需，两者整合有市场 |
| **PinToDesk** | 桌面挂件待办，鼠标穿透、悬停才显示操作图标 | 待办可以不只在搜索框里，还能"驻"在桌面上 |

### 3. 剪贴板管理类

- **Ditto / ClipX / CopyQ / Paste**、Windows 自带 `Win+V`
- 共性能力：历史记录、搜索、固定（pin）、纯文本粘贴、多格式预览（文本/图片/HTML）
- 参考：WinKit、Raycast 的剪贴板历史

### 4. 截图 / OCR 类

- **Snipaste**：截图 + 贴图（截图钉在屏幕上）
- **Umi-OCR**：本地离线 OCR（PaddleOCR），截图/批量/PDF
- **SnapFind**：截图 OCR + 搜索，纯本地，常驻 ~10MB
- 参考：PowerToys Text Extractor

### 5. 待办 / 便签类

- **Kite 待办**：极简、即开即用
- **vivo 原子笔记**：任务划掉完成（项目文档里已参考）
- 滴答清单 / 微软待办：多端同步、提醒

### 6. AI 趋势（2024–2026）

- **Raycast AI**：AI 对话、AI 总结、智能命令
- **OpenAI Translator（Raycast 插件）**：划词/剪贴板翻译
- **阿里千问"驻桌"**：桌面 AI 助理成为 PC 新入口方向
- 启发：翻译、总结、自然语言命令是未来方向，但学习项目可以先做本地规则版本

## 二、功能构思清单（按优先级分阶段）

> 标记说明：⭐ = 强烈建议（高频刚需 / 与现有架构契合）；🔧 = 实现难度低（纯逻辑或 Qt 内置）；🪟 = 需要 Win32 API

### Phase 3（原计划，建议照做）

1. **剪贴板历史** ⭐ 🪟
   - 监听系统剪贴板（Win32 `AddClipboardFormatListener` 或定时轮询），存 SQLite
   - 支持文本/图片/HTML 多格式，列表预览 + 关键词搜索
   - 固定（pin）、一键粘贴到前台窗口、纯文本粘贴（去格式）
   - 参考 Ditto / WinKit；注意隐私设置（可设置不记录敏感应用）
2. **待办事项** ⭐
   - 三张表架构可扩展一张 `todo` 表；完成划去、优先级、截止日期
   - 可先做搜索框内输入触发，后续参考 PinToDesk 做桌面挂件
3. **设置面板**
   - 热键自定义（呼出键、剪贴板键…）、主题、开机自启、数据库清理

### Phase 3.5（纯逻辑练手，低成本高感知）

4. **网页搜索**：输入 `gg 关键词` / 直接输入 → 调用默认浏览器打开搜索引擎，聚合多引擎
5. **翻译** 🔧：中英互译（先做本地词库/在线 API 二选一，建议 API + 缓存），划词翻译后续
6. **文本工具** 🔧：大小写转换、去重行、排序、Base64 编解码、URL 编解码、JSON 格式化、时间戳 ↔ 日期
7. **单位换算** 🔧：长度/重量/温度/进制（十进制↔十六进制↔二进制）
8. **颜色工具** 🔧：Hex ↔ RGB 互转 + 预览色块
9. **网址直达/书签搜索**：收藏常用网址，输入即打开
10. **系统快捷命令** 🔧：锁屏、睡眠、关机、清空回收站、打开常用文件夹/系统设置页

### Phase 4（Win32 API 深入，学习价值高）

11. **窗口管理** 🪟：窗口置顶（`SetWindowPos`）、透明度调节、快速分屏（`MoveWindow` 到半屏）
12. **屏幕取色** 🪟：全局鼠标取色，输出 Hex/RGB（参考 PowerToys Color Picker）
13. **截图 OCR** 🪟：先接 Windows 自带 `Windows.Media.Ocr`（零依赖），后续可换 PaddleOCR 做离线识别
14. **批量重命名** 🪟：PowerRename 简化版（查找替换/加前缀后缀/序号）
15. **快捷短语（Snippets）**：常用文本模板一键插入（参考 Flow Launcher Snippets）

### Phase 5+（探索方向）

16. **自然语言命令**：输入"打开微信""搜一下量子计算"→ 解析意图分发（先用规则，后续接 LLM）
17. **AI 对话/总结**：接入 API（可插拔 provider），做选中文案总结、翻译增强
18. **插件化架构**：uTools 模式——注册中心 + 插件接口，让每个功能变成独立插件
19. **工作流/动作面板**：Quicker 式多步动作
20. **Everything SDK 集成**：文件搜索提速到毫秒级（当前 QDirIterator 索引有上限）
21. **天气/日历提醒**：启动时弹窗提醒重要日期（项目文档已有此构思）

## 三、架构建议

- **统一搜索框是核心**：所有功能最终都收敛为"输入 → SearchResult 列表"，现有 `SearchResult.type` + FuzzyMatcher 已打好底子，新功能 = 新增 type + 注册一个 Provider
- **建议引入"Provider"抽象**：每个功能模块实现 `search(query) -> vector<SearchResult>`，AppBridge 统一收集聚合。为 Phase 5 插件化预留接口
- **数据层统一走 SQLite**：剪贴板、待办、短语、书签都建表，HistoryDatabase 的模式可以复用
- **命令前缀约定**：如 `t ` 待办、`cp ` 剪贴板、`hex ` 进制转换——uTools/Listary 已验证这种交互可行，实现简单
